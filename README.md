# Witherfate website

The public website for [Witherfate](https://witherfate.com), a premium online-first action RPG built around persistent accomplishment, intentional cooperation, and an authored dark-fantasy world.

The site contains an externally shareable overview of the game’s established design philosophy. Detailed and exploratory design work remains in the private `witherfate-design` repository.

## Development

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
